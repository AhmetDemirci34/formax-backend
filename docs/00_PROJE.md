# Product Vision

FORMAX is **not** a livescore application.

FORMAX is **not** a betting application.

FORMMAX is **not** a statistics application.

FORMAX is an AI-powered football discovery platform where artificial intelligence guides users through every match.

The product answers one core question:

> **"What should I know about this match right now?"**

Instead of overwhelming users with statistics, FORMAX uses AI to prioritize, explain, visualize and guide.

---

# Core Philosophy

AI is the primary interface.

Data supports AI.

Users explore the match together with AI.

Everything begins with AI.

---

# Match Intelligence

The Match Intelligence screen is the heart of FORMAX.

It is **not** a traditional Match Detail page.

There are:

* No Tabs
* No Accordions
* No Multi-page Detail Screens
* No Dashboard Layouts

Instead,

The entire experience happens inside one living workspace.

# Product Principles

Every screen must satisfy these rules.

## Rule 01

AI speaks first.

## Rule 02

The screen transforms instead of navigating.

## Rule 03

Only one story is told at a time.

## Rule 04

Every experience has exactly one Hero Visual.

## Rule 05

AI is a guide, not a chatbot.

## Rule 06

Every AI opinion must be supported by evidence.

## Rule 07

Animations are event-driven.

Never decorative.

## Rule 08

The interface must feel calm.

Never noisy.

# Personal AI

Personal AI is intentionally postponed.

The current UI must work perfectly without personalization.

Future phases will integrate:

* Interest Engine
* Session Memory
* Personalized AI Greetings
* Dynamic Action Ranking
* Learning Engine

No UI redesign will be required.

Only behaviour changes.
